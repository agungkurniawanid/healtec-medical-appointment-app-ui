Healtec — Medical Appointment App UI
Healtec adalah aplikasi mobile berbasis Flutter yang dirancang sebagai antarmuka platform pemesanan janji dokter. Aplikasi ini menampilkan desain UI yang modern dan bersih, cocok sebagai referensi atau fondasi pengembangan aplikasi kesehatan digital.

Fitur Utama
Onboarding Screen
Layar pembuka yang menyambut pengguna baru dengan ilustrasi dokter, tagline aplikasi, dan tombol mulai. Memberikan kesan pertama yang profesional dan meyakinkan.

Home Screen
Halaman utama yang menampilkan:

Profil pengguna dan salam personal
Filter kategori penyakit (Demam, Batuk, Mual, Flu, dan lainnya) untuk memudahkan pencarian dokter sesuai keluhan
Daftar Favourite Doctors untuk akses cepat ke dokter yang sering dikunjungi
Daftar Top Doctors dengan informasi spesialisasi, klinik, rating, dan jumlah ulasan
Appointment Detail Screen
Halaman detail janji dokter yang menampilkan:

Foto dan informasi lengkap dokter
Badge statistik: jumlah pasien, tahun pengalaman, rating, dan jumlah ulasan
Tombol navigasi ke sesi konsultasi
Appointment Voice Call Screen
Layar simulasi panggilan suara dengan dokter, menampilkan:

Foto dokter sebagai latar belakang dengan efek blur dan overlay gelap
Nama dan spesialisasi dokter
Kontrol panggilan (speaker, mute, kamera, end call)
Bottom Navigation Bar
Navigasi utama dengan empat tab: Home, Jadwal (Calendar), Pesan (Chat), dan Profil — dikelola menggunakan Riverpod untuk perpindahan antar halaman yang mulus.

Teknologi yang Digunakan
Teknologi	Kegunaan
Flutter	Framework UI lintas platform
Dart	Bahasa pemrograman utama
Riverpod	State management (bottom nav, system UI)
Google Fonts	Tipografi konsisten dengan font Roboto
Font Awesome Flutter	Ikon berkualitas tinggi di seluruh UI
Tujuan Proyek
Proyek ini dibuat sebagai implementasi UI untuk mendemonstrasikan kemampuan desain antarmuka aplikasi kesehatan yang intuitif, responsif, dan siap dikembangkan lebih lanjut menjadi aplikasi penuh dengan integrasi backend.
